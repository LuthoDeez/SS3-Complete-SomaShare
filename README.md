Project description

We’ve developed a web-based platform called SomaShare to make it safe and easy for students to purchase, sell, and trade textbooks as well as other study-related goods. Users can create adverts, browse listings, make offers, and manage transactions through an organized system.

Setup instructions

Applications needed

Visual Studio 2022

.NET SDK installed

SQL Server Management Studio (optional)

SQL Server / SQL Server Express

How to Run the Project

Clone the repository

Open the solution file: SomaShare.sln

Check your connection string inside: appsettings.json

Open Package Manager Console and run: update-database

Run the application: Press F5 in Visual Studio

Technologies used

ASP.NET Core MVC

Entity Framework Core

SQL Server

ASP.NET Identity

Razor Pages / Views

Visual Studio

Note:

Ensure SQL Server is running before launching the project.
